# Repository map

- `AGENTS.md`: single source of truth for relay rules.
- `docs/MASTER_DIRECTIVE.md`: owner-provided master directive and addendums.
- `docs/`: status, architecture, incidents, and product documentation.
- `.ai/`: relay state, tasks, logs, reviews, decisions, context, and issue records.
- `.cursor/`: tool-specific pointer rules.
- `.github/`: repository security docs and Actions workflows.
- `src/`: React UI and browser-safe client helpers.
- `functions/`: Cloudflare Pages Function API handlers and shared server helpers.
- `supabase/migrations/`: forward-only database migrations.
- `public/`: static assets and route manifest.
- `research/`: dated provider, taxonomy, and policy research; historical concept is archived.
- `plan.md` and `TODO.md`: current product source of truth.

# Launch checklist

Launch is blocked until the owner configures Cloudflare Pages, Supabase, production environment values, email confirmation/SMTP, a verified moderator account, and a monitored grievance path. The team must then run account, upload, moderation, download, report/takedown, removal, and object-cleanup flows with real providers. The public URL, domain, policy pages, and contact details require owner/legal review. The 18+ flag and ads remain off.

Owner-only GitHub settings: open the repository on GitHub, choose **Settings → Code security and analysis**, enable Dependabot alerts, secret scanning, push protection, and CodeQL where GitHub offers them, then send one screenshot of the enabled statuses. No token or password should be sent in chat.

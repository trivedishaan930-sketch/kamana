# Gallery Ash design system

Gallery Ash uses warm museum-paper surfaces, ink-blue navigation, editorial serif headings, restrained safety labels, and generous image-first composition. Use a responsive masonry-like visual rhythm without sacrificing readable source order or keyboard focus. The signature elements are the ink-blue navigation rail, paper cards with quiet borders, and a visible AI-generated provenance stamp.

Typography should pair a readable editorial serif for headings with a neutral sans-serif for controls and metadata. Color contrast must be checked rather than assumed. Every interactive element needs visible focus, a text label or accessible name, and a touch target suitable for mobile. Images need useful alt text; decorative art must be marked decorative.

Animation should be short, optional where motion sensitivity applies, and never hide safety or moderation status. Sensitive previews must not be revealed by hover-only interaction.

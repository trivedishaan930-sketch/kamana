# Kamna roadmap

Status date: 2026-11-10. Roadmap approval is recorded; the current beta deployment and Supabase Auth Step 3 are complete, while broader launch gates remain open. Storage: separate directive.

## Phase 0 — stabilise and audit

Acceptance: status report exists; CI typecheck/build is green; `tsconfig.tsbuildinfo` is not tracked; personal contact cleanup is reviewed; owner-only GitHub security settings are checked; product docs match the real route manifest; known issues remain honest.

## Phase 1 — go-live foundations

Acceptance: owner connects Cloudflare Pages and Supabase from dashboards; forward-only migrations are tested on an approved staging plan if available; environment values are entered only in dashboards; a moderator account and email path are verified; private beta approval is recorded. No public launch occurs before end-to-end evidence.

## Phase 2 — core product quality

Acceptance: masonry-like responsive gallery, search/tags, artwork pages, upload flow, keyboard/accessibility checks, performance baseline, and reviewed policy pages are verified. App changes require roadmap approval.

## Phase 3 — trust and safety hardening

Acceptance: server-side permission checks, rate limits, upload byte validation, moderation audit, takedown handling, abuse controls, incident drill, and independent security review are evidenced.

## Phase 4 — SEO and discovery

Acceptance: crawlable approved routes, sitemap/robots, canonical metadata, social cards, accurate JSON-LD, Search Console setup, and measured Core Web Vitals are verified. No indexation of private/admin/closed 18+ content.

## Phase 5 — growth and community

Acceptance: private-beta feedback supports onboarding, collections, sharing, featured artists, and weekly themes. No feature is adopted from a proposal without decision records.

## Phase 6 — monetization

Acceptance: real traffic baseline, provider/policy review, owner Yes, and cost guardrails exist. No income promise is made.

## Phase 7 — maintenance

Acceptance: weekly security audit, dependency updates, Scout report, issue review, and rollback rehearsal are scheduled and logged.

# Product docs index

The product set is grouped as vision/requirements (`VISION.md`, `PRD.md`), planning/navigation (`ROADMAP.md`, `SITEMAP.md`, `INFORMATION_ARCHITECTURE.md`), design/research (`DESIGN_SYSTEM.md`, `MARKET_RESEARCH.md`, `UX_RESEARCH.md`, `WIREFRAMES.md`), operations (`SECURITY_PLAN.md`, `QA_PLAN.md`, `LAUNCH_CHECKLIST.md`, `OWNER_GUIDE.md`, `SERVICES_REGISTER.md`, `COMPLIANCE_REGISTER.md`), and product flows (`USER_JOURNEYS.md`, `ROLES_AND_PERMISSIONS.md`, `ADMIN_PANEL_SPEC.md`, `CONTENT_FLOW.md`, `VALUE_AND_BUSINESS.md`, `MONETIZATION.md`, `SEO_GROWTH.md`).

Every document ends with a short Hindi owner summary. Claims that need external evidence include a source/date or are marked unknown.

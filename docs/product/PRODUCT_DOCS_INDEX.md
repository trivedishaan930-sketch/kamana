# Product docs index

The product set is grouped as vision and owner requirements (`VISION.md`, `OWNER_BRIEF.md`, `PRD.md`), planning and navigation (`ROADMAP.md`, `SITEMAP.md`, `INFORMATION_ARCHITECTURE.md`), design and research (`DESIGN_SYSTEM.md`, `MARKET_RESEARCH.md`, `UX_RESEARCH.md`, `WIREFRAMES.md`), operations (`SECURITY_PLAN.md`, `QA_PLAN.md`, `LAUNCH_CHECKLIST.md`, `OWNER_GUIDE.md`, `SERVICES_REGISTER.md`, `COMPLIANCE_REGISTER.md`), and product flows (`USER_JOURNEYS.md`, `ROLES_AND_PERMISSIONS.md`, `ADMIN_PANEL_SPEC.md`, `CONTENT_FLOW.md`, `VALUE_AND_BUSINESS.md`, `MONETIZATION.md`, `SEO_GROWTH.md`).

`OWNER_BRIEF.md` records the owner's current product goals and measured baseline; `PRD.md`, `ROADMAP.md`, `.ai/TASKS.md`, and the first post-approval code task derive from it. The 2026-11-10 monetization screening is documented in `MONETIZATION.md`, `SERVICES_REGISTER.md`, and `VALUE_AND_BUSINESS.md` with direct provider sources and unknowns.

Every document ends with a short Hindi owner summary. External factual claims carry a source/date; unknowns are marked as unknown. Legal notes are not compliance claims and need a qualified lawyer's review.

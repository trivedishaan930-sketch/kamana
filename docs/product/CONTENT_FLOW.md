# Content creation flow

The creator signs in, opens upload, chooses JPG/PNG/WebP within the current size rule, sees a local preview, enters title/description/tags/category/rating, records tool/model/process when available, confirms AI generation and publishing rights, confirms safety rules, and submits to pending review. The UI must state that confirmation is not automated AI detection.

Statuses are pending, approved, rejected with a reason, and removed. Edits to approved content should return it to review where policy requires. Deletion/takedown must remove public visibility first and complete object cleanup with retry evidence. Tags and categories must use controlled labels and keep each Indian tradition distinct.

Moderator checklist: AI-only disclosure present; rights confirmation; prohibited-content screen; age ambiguity; real-person likeness/deepfake concern; cultural-label accuracy; metadata quality; sensitive preview; report history; and reasoned decision.
